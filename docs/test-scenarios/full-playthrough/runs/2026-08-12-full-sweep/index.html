What the run got wrong

Four of the nine issues asserted something about the code that turned out to be false. Kept here because a run that only records its hits isn't much of a record.

  • #113 asked for all five biomass fuels at tier 0. Solid Biofuel belongs at 2 — Recipe_Biofuel_C is a Tier 2 recipe, so tier 0 would have been #115's own bug in reverse.
  • #115 said Tier 0 unlocks nine products. It's eight; the three wrong rows had been counted into the total.
  • #116 claimed the factory card anchors near its pin and that an unclaimed node's yield is hidden. The card is docked bottom-right, and the yield is genuinely 0 until a claim exists.
  • #119.3 asked for the claim row to follow the editor live. That row was frozen deliberately under #49, with a test guarding it.
